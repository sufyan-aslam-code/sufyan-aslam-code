- Multi-turn conversation memory with LangGraph MemorySaver
- History-aware query processing
- Semantic retrieval using ChromaDB
- Grounded responses from retrieved context

**Stack:** Python · FastAPI · React · LangGraph · ChromaDB · Tailwind CSS

**Links:** [Repository](https://github.com/sufyan-aslam-code/iiui-nexus-agentic-rag) · [Portfolio](https://www.sufyanaslam.me)

### Agentic AI Assistant — Dual-Routing LLM Architecture
An AI assistant that dynamically routes requests between a local RAG pipeline and real-time web search.

**Highlights**
- LangGraph-based autonomous routing
- Local document retrieval through Qdrant
- Real-time web search with Tavily
- PDF ingestion using PyMuPDF
- React/Tailwind multi-session chat interface
- Citation handling and controllable AI execution

**Stack:** Python · FastAPI · React · LangGraph · Qdrant · Tavily · Tailwind CSS

**Links:** [Repository](https://github.com/sufyan-aslam-code/agentic-ai-assistant) · [Portfolio](https://www.sufyanaslam.me)
